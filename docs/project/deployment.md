# ViewHub 部署与运维

## 启动

在仓库根目录执行，宿主需要 Docker Engine 与支持 include 的 Compose。根 `compose.yaml` 保留启动入口，具体服务定义在 `apps/platform/compose.yaml`；构建使用 `apps/platform/Dockerfile` 和仓库根上下文。

1. 将 `.env.example` 复制为 `.env`，填写公网媒体地址 `PUBLIC_IP`。已有站点继续使用原来的 `SIP_ID`、`SIP_REALM`、SIP 与媒体端口。
2. 创建 `secrets/web.password`，用于初始化管理员。已有实例保留原 SQLite 数据卷和账号。
3. 执行 `docker compose config --quiet` 和 `docker compose up -d --build`。按 `apps/platform/deploy/viewhub.caddy` 配置 HTTPS 反向代理，默认域名为 `viewhub.xliyun.com`。
4. 请求 `/healthz` 核对版本，登录确认设备注册、通道发现和实际出画。

| 位置 | 默认端口 | 用途 |
| --- | --- | --- |
| 云端公网 | TCP 443、80 | HTTPS，80 用于跳转或证书申请 |
| 云端公网 | UDP 和 TCP 5060 | 国标 SIP |
| 云端公网 | UDP、TCP 10000–10099 | 国标媒体，按 `RTP_FIRST` 和 `RTP_LAST` 调整；主动 TCP 对讲需同时放行 TCP |
| 云端公网 | UDP 8191 | 浏览器 WebRTC，按 `ICE_PORT` 调整 |
| 云端回环 | TCP 18481 | HTTPS 反向代理的应用上游 |

## 国标验收

- 在设备端配置平台接入。确认设备注册、心跳和通道发现，再用公网浏览器实测实时播放。
- 录像机装盘并完成初始化。用至少两路通道录制已知时段并留出断档，对照录像机本地目录核对 ViewHub 的按日期查询、通道、时区和断档。
- 从时间轴选段内时刻起播，测试连续跳转和切换通道。点停止后核对 SIP BYE 和 RTP 停止。分别实测关闭标签页及断网。
- 两个客户空间交叉验证设备列表、监控墙、实时、录像和云台权限。云台用有电动云台的通道验收。
- 本地开发验证执行 `go test ./...`。在 `apps/platform/web` 执行 `npm ci` 和 `npm run build`。

### USB 设备端与自动恢复

USB 摄像头由 `apps/capture` 设备端接入。分辨率、输出帧率、画质、最大码率和 H.264/H.265 可在本机 React + shadcn/ui 页面选择；先停止设备再保存配置。最大码率默认采用建议值，可手动调整；旧目标码率数值迁移为手动上限。检测设备可读取 Windows 摄像头实际 MJPEG 规格，后台自动优先 NVIDIA、其次 Intel、最后 CPU，FFmpeg 需包含所用编码器并具有相应设备和驱动权限。配置、密码和本地录像不得加入仓库。

实时播放器在断流后保留观看意图并自动重新点播，手动停止、切换通道或进入录像回放取消重连。验收须保持页面不刷新，持续中断本路设备通信超过 100 秒，恢复链路后观察新会话自动出画；同时确认停止后 FFmpeg 退出、服务端 RTP 安静，以及权限失败不会无限重试。不得为单台设备验收中断整个平台或其他设备。

## 对讲与设备移除

- 对讲采用国标 Broadcast 通知、设备发起 INVITE、平台返回 SDP 和 ACK 确认的流程。当前支持 G.711A/PCMA 8 kHz；TCP 使用 RFC 4571 长度前缀，支持设备主动或被动建立连接，也支持 UDP。NAT 环境优先在设备端选择主动 TCP。
- HTTPS 页面由用户主动开启麦克风。浏览器通过独立 WebRTC 音频会话发送麦克风数据；现场声音来自实时码流中的 G.711A 音轨，因此不依赖视频是否回退为兼容播放。
- Docker 端口映射和云安全组都要覆盖实际配置的媒体 TCP 范围。先验证服务器本机映射，再验证外部连接；容器已映射不代表云安全组已经放行。
- 验收时核对设备握手、双向 RTP、静音、停止、切换通道、关闭页面及退出登录。没有收到现场音频时，页面应说明状态，不能仅凭握手成功宣布双向对讲可听。
- 删除设备会在归属校验后清理库存、通道、云台能力和监控墙关联，结束相关观看及对讲会话；不会删除设备本地录像或重置设备。

### 兼容播放的声音监听

WebCodecs/HLS 视频回退后，点击声音按钮通过当前观看会话的 `POST /api/session/{token}/whep?audio=1` 建立仅接收 PCMA 的连接，不发送 Broadcast，不申请麦克风，不新增设备点播。接口沿用服务端观看会话归属检查。响应 Location 指向独立监听资源；关闭声音立即 DELETE 该资源，原视频继续播放。同一观看会话只保留一个独立监听，停止观看、注销或设备移除后会话失效并清理音频连接。没有音频包、协商失败或浏览器拒绝播放时显示原因，可关闭声音后重试。


### 播放器显示与音量

声音图标悬停或键盘聚焦时显示 0–100% 音量条。普通 WebRTC 设置视频元素音量，兼容模式设置独立监听音频元素音量，均不操作系统音量，也不重新协商连接。已在水星 WebCodecs 实播验证 90%、0%、恢复非零值及 100% 操作，音频包持续增加，停止后音视频元素移除。

右侧图像调整提供亮度、对比度、饱和度和原始/提亮/通透预设，以及原图对比、一键还原。只是本地观看滤镜，默认不启用，不改变录像或摄像头编码配置。实测视频输入为 2880×1624 H.265；滤镜值变化与还原 none 已在实际播放中核对。画质比较仍需结合镜头、曝光、照明、码率及降噪设置，不能把显示滤镜视为恢复原本不存在的细节。

### 云台按住操作与播放恢复

方向操作发送 `hold=true`，成功后每约250毫秒续期。服务端续期有效期900毫秒，超时主动发停止；松开显式停止，保持串行请求，页面关闭或失焦也结束操作。未带 hold 的原有方向与变焦接口仍是500毫秒点动，预置位不变。接口继续检查客户空间归属和通道云台能力。

验收需覆盖长按超过500毫秒、松开、触屏取消、失焦及离开页面；协议确认不等同于摄像头实际有云台。单画面和监控墙加载失败均可点「重新播放」重新建立观看会话，点击在线通道自动播放；监控墙全屏应包含所有格位，配置格位前先退出全屏以显示配置对话框。
