# ViewHub 轻边缘接入与历史回放

## 设备与现场

局域网设备由当前客户空间的现场盒子接入。用户管理摄像头和硬盘录像机。摄像头检测实时与云台，录像机按设备归集通道，通过 ONVIF Profile G 提供历史时段和回放。相同地址匹配多个现场时暂停接入，交由运维确认归属。国标和 Frigate 沿用各自的媒体链路。

## 从网页接入设备

1. 在设备上启用 ONVIF，创建具有相应权限的账号。录像机账号需要支持录像搜索和回放。
2. 打开 **设备接入 → 接入 ONVIF 摄像头** 或 **接入 ONVIF 录像机**。填写名称、局域网 IPv4 地址和账号，必要时在连接选项中指定端口及 HTTPS。平台按当前客户空间和可访问网段匹配在线轻边缘网关。
3. 点击 **检测通道**。摄像头选择实时视频配置。录像机选择要接入的录像通道，可调整录像轨道和实时视频配置。设备公开可匹配的 ONVIF 源标识时，ViewHub 自动关联对应实时配置。没有关联实时配置的通道仅提供录像。
4. 在视频工作台选择历史录像和日期。用时间轴拖动或跳到指定时刻。在设备通道列表可移除由网页接入的 ONVIF 通道。

手工配置时，`deploy/edge.example.json` 展示 ONVIF Device Service URL、录像 token、可选轨道 `track` 和 PTZ 配置 `profile`。只有一条视频轨道时可由录像信息自动选择。明确配置的 ONVIF 录像优先于 Frigate 录像适配。Profile G 返回不支持时，只有配置了海康 ISAPI 的通道才可回退到 ISAPI。

## 回放与首帧

日期查询绘制录像时段和断档。时间轴跳转发出绝对时刻，实际首帧取决于录像机和关键帧。轻边缘首版为 H.264 无转码。WebRTC ICE 协商最长 5 秒，确认直连后才发开播票并拉录像。协商失败直接走 HTTP + fMP4。WebRTC 起播后 4 秒未呈现第一帧，或直连中断，回退一次。回退沿用原截止时间，从最近实际呈现的录像位置接续。回退先释放旧 RTSP 会话。录像机目录、权限或地址错误直接显示。两条链路按媒体时钟限制上游预读。

盒子通过 RTSP/TCP 向录像机请求录像，向浏览器提供 H.264 WebRTC 或 fMP4。中继时 FFmpeg 复制视频编码并重新封装。若需要给回放声明显式 ICE 候选地址，将 `VIEWHUB_REPLAY_ICE_IP` 设为浏览器可达的地址。

## 播放票与隔离

- 云端签发命令票，绑定登录、通道、观看窗口、播放版本、命令和签发时间。盒子验证签名。票超过 3 秒或超前超过 1 秒即拒收，现场时钟需同步。
- 浏览器每 3 秒检查是否仍处于播放状态、呈现了新帧且媒体位置前进。三项满足才上报。切到中继后，一旦有第一份有效进度即可上报，续票之间至少间隔 3 秒。盒子检查当前版本、传输方式、递增序号、帧计数和位置，然后续期。每次接受有效票后，以盒子本地单调时钟计算 10 秒截止时间，边缘计时器预留 100 毫秒给连接关闭。
- 迟到、重复、跨版本和已到期会话的续票均无法延长播放。暂停、停止、离开时通知盒子释放上游，通知丢失由租约到期兜底。恢复从最后实际呈现位置重新开播。
- 确认跳转时创建新版本和新媒体元素。盒子关闭旧上游，浏览器清空旧视频缓冲并忽略旧回调。快速跳转以最高版本为准。回退也清空旧媒体连接，沿用原版本和截止时间。
- 浏览器崩溃、画面停滞和云端失联时，盒子停止收到有效票，即使 P2P 还能传输也会到期停流。盒子进程冻结需独立监督，单独验证。

## 验收

分别用 WebRTC 直连与 fMP4 中继验证正常续播、首帧超时、断线回退、暂停、快速跳转、迟到票和重复票。模拟浏览器崩溃及云端失联。**以盒子最后接受有效票的单调时间为起点，10 秒内关闭对应 RTSP 连接并停止视频上行**。记录最后一个媒体包和连接关闭的时刻，工具误差单列。浏览器已缓冲画面可短暂继续播放。其他观看会话和本地录像独立计时。公网直连用 ICE 候选对和云端媒体字节验真，实体录像机按型号联调。
