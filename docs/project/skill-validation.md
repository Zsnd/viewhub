## 公网自动恢复与编码选项续验

本轮继续按故障证据定位：先记录旧播放器 3 轮重复点播与 WebRTC 接收端统计，未重现此前的持续全部丢帧，因而不把它武断归为网络丢包。确认的代码缺口是终止观看意图、重复 srcObject 赋值、把丢弃帧计作进度及设备端旧媒体会话不随失联释放。修改后用至少 100 秒单设备双向断线和同文档标记验证自动恢复，再做 H.264 三轮、H.265 两轮重复点播稳定段采样。

shadcn CLI 生成 NativeSelect 时再次引入 `cn` 包；已审阅生成文件、改为项目工具函数并移除多余依赖。配置页实际通过下拉框保存分辨率、帧率、码率及 H.265，能力检测返回五种真实摄像头规格。Impeccable 机械检查无告警；本轮标准截图接口超时，替代 CDP 截图未展示目标页面，已目视检查后判为无效证据，没有计作视觉验收通过。浏览器 DOM、交互与配置生效验证已完成。

本轮没有建立隔离 A/B，也不把重连和编码实现效果归因于安装技能。AV1 经用户明确确认延期。FFmpeg 范围警告通过真实输入/输出格式和显式转换核对，仍保留原警告，不以屏蔽日志冒充修复。
