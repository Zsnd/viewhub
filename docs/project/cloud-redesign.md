# 云端产品与界面重设计方案

状态：用户已确认日常监看优先，兼顾设备管理。0.6.0 界面已实现并部署，设计终审通过；公网媒体 TCP 已验证连通，两路视频已出画；浏览器真实语音可听验收受本机缺少麦克风限制。

## 目标与范围

基于任务重新组织 ViewHub 的功能、导航、页面和交互，不沿用现有页面布局。前端使用 React 与 shadcn/ui，国标信令和媒体服务保留 Go。

已确认需求：设备接入和删除规范化、实时预览、多画面监看、录像回放、按通道能力显示云台操作、补齐国标对讲，以及复测水星固件升级后的认证兼容性。

主要使用场景已确认为日常监看优先，兼顾设备管理。

## 信息架构

| 入口 | 用户任务 | 主要内容与操作 |
| --- | --- | --- |
| 视频监控 | 查看实时画面、回看录像、操作设备 | 设备与通道状态、单画面与分屏、通道内切换实时/回放、日期与时间轴、右侧图标云台和语音对讲 |
| 设备管理 | 接入、配置、检查和移除设备 | 设备列表、添加向导、接入详情、通道能力、编辑、删除 |

## 实时监控

桌面端采用导航、通道目录、视频工作区三层结构。主工作区尽量留给视频；选中通道后，按实际能力显示右侧操作面板。多画面与单画面属于同一任务，避免在两个独立页面重复找通道。

- 顶部显示当前工作区、分屏选择和全屏；设备维护入口放在通道更多操作中。
- 通道目录支持名称搜索、在线状态筛选和按设备展开；搜索结果保留设备名称，避免同名通道混淆。
- 每个画面显示通道名称、播放状态和必要控制。设备在线与视频正在播放是两个不同状态。视频直角、等比例居中；播放、暂停、停止、声音、全屏统一为画面底部图标栏，日期与时间轴保持在画面下方。
- 当前选中的画面有稳定的选中标记，云台和对讲始终指向该通道。
- 云台只对启用的通道显示；能力未知时在设备详情允许人工配置，不能把未知直接当成不支持。
- 切换通道、停止播放、退出登录和移除设备时，释放对应会话。离线画面提供可理解的原因及重试入口。
- 小屏使用折叠目录选择通道，云台与对讲排在画面下方，视频不被永久侧栏挤压。

## 录像回放

回放整合在视频监控工作区，保持当前通道，通过画面上方的实时/回放切换操作。切换时释放当前播放和对讲会话；回放期间禁用云台及对讲。

- 先选择提供录像查询的通道和日期，再显示当日录像片段。
- 时间轴区分有录像和空白区域。跳转到空白时显示“该时刻没有录像”，不启动无效会话。
- 播放、暂停、停止和精确时间跳转位置固定；查询中、无录像、设备离线及查询失败分别呈现。
- 明确录像来自现场设备。尚未实现的下载、云存储或检索功能不以可操作按钮呈现。

## 设备生命周期

### 添加

添加采用明确的步骤：登记设备 → 配置现场设备 → 等待注册与发现通道 → 完成。

1. 登记设备：名称、摄像头或录像机、20 位设备编码、国标注册密码。区分平台注册密码与摄像头管理密码。
2. 现场配置：逐项展示 SIP 地址、端口、服务器 ID、域、设备 ID、认证 ID 和密码，支持单项复制。密码默认隐藏，按需查看。
3. 注册验证：展示等待注册、认证失败、已注册、正在发现通道和发现完成；页面刷新后仍能从设备详情继续。
4. 完成：显示发现的通道和能力，提供“查看实时画面”。通道发现失败时保留已登记设备并允许重试。

表单错误贴近字段显示；提交失败保留输入；提交期间防止重复操作。关闭向导不会暗示撤销已经登记的设备。

### 列表与详情

列表采用标准表格：名称、类型、注册状态、通道数、最近信令时间、操作。支持搜索与状态筛选，区分首次空列表和筛选无结果。

点击名称进入设备详情，按“概况与诊断 / 通道 / 接入参数”组织。注册状态、视频播放状态、通道发现状态分别显示。诊断信息先说明如何恢复，再按需展开技术原因。

通道配置显示名称、编码、云台能力及其来源（设备上报、人工配置、未知）。人工覆盖可恢复自动识别。对讲能力需经过协议协商或实测确认，不能只凭型号宣称支持。

编辑允许修改名称、设备类型和注册密码；设备编码作为稳定标识保持只读。修改密码时说明现场设备需要同步修改。

### 删除

删除放入设备行和详情的更多操作菜单。确认弹窗包含设备名称、编码与影响：解除平台接入、停止相关会话、清空监控墙关联；不删除设备本地录像，也不重置现场设备。

确认后才调用删除接口。失败保留弹窗并显示原因；成功关闭详情、刷新列表和监控墙。服务端检查客户空间归属，并将库存与关联清理作为事务处理。

## 对讲

对讲属于当前选中通道的操作，初次使用由用户点击后请求麦克风权限。

| 状态 | 页面反馈 | 可执行操作 |
| --- | --- | --- |
| 能力未知 | 尚未验证对讲支持情况 | 发起连接并协商；失败显示具体原因 |
| 离线或不支持 | 显示原因 | 不提供可误触的讲话入口 |
| 请求麦克风权限 | 浏览器正在请求权限 | 取消 |
| 正在连接 | 正在建立对讲 | 取消 |
| 已连接 | 明确提示麦克风是否正在发送，显示持续时间 | 静音、结束 |
| 被占用 | 设备正在被其他会话使用 | 稍后重试 |
| 断开或失败 | 显示可恢复原因 | 重试、关闭 |

监听音量与麦克风发送分开控制。对讲结束、切换通道、离开工作区、连接中断和退出登录时，停止麦克风采集并释放设备端会话。

实现需要验证浏览器音频采集、音频编码、国标信令、RTP 传输及现场设备发声。只有完成媒体与现场验证后才标记可用；单向喊话不能标成已经实现双向对讲。

## 视觉与组件原则

- shadcn/ui 提供统一的按钮、输入框、选择器、表格、标签、对话框、抽屉和菜单；业务页面共享同一组状态和反馈规则。
- 管理页面采用清晰的浅色工作区；视频区域使用深色背景，保证画面优先。最终视觉方案在主要场景确认后细化。
- 主操作使用明确文字，危险操作只在确有破坏含义时使用危险色。
- 侧栏负责导航，表格负责检索与比较，详情负责诊断，弹窗负责短任务；避免在一个大弹窗里塞入所有设备功能。
- 所有交互支持键盘、可见焦点、可读标签和窄屏布局。抽屉与弹窗关闭后焦点返回触发入口。

## 播放器控制层交互

参考 Video.js 与 Vidstack 官方控制层设计，实时和回放共用 PlayerSurface 活动检测。工具条叠加在画面上，正常播放闲置 2.5 秒后以 180ms 淡出；鼠标移动、键盘交互可唤出。未播放、连接中、暂停及错误状态保持可见。鼠标悬停工具条或键盘聚焦控件时保持显示。触屏轻点画面切换显隐，操作按钮不会同时切换控制层。停止使用实心直角方块并保留国标会话释放。系统减少动态效果偏好取消过渡动画。

参考：https://videojs.org/docs/framework/html/guides/controls 、https://vidstack.io/docs/player/components/display/controls/


WebCodecs 实时监听验收：独立只接收 WebRTC 音频已部署，水星两路均在浏览器解码并播放，用户逐路确认实际可听。静音、通道切换及停止的清理完成验证。本项不涉及麦克风发送，原真实麦克风对讲验收限制仍单独保留。
